🚀 Latest Update

Version 0.4 — 2026‑07‑27

Major interactivity upgrade: a cargo-sorting mini-game in the hero, an interactive roadmap with voting, a live notification system, a confetti easter egg, a stats comparison demo (since Roblox API is content-restricted), and a game-style loading screen.

  • Cargo-sorting mini-game directly on the homepage — click boxes to sort by type.
  • Interactive product roadmap with upvote buttons (stats persisted to localStorage).
  • Notification toast system that shows tips and announcements on a rotation.
  • Konami code easter egg that triggers a cargo confetti party.
  • Scroll progress bar at the top of the page.
  • Floating cargo emojis around the hero image.
  • Stats demo mode: when the Roblox API is content-restricted, shows simulated numbers so the chart still tells a story.
  • Game-style loading screen on first visit for theme consistency.
  • Collaborate form now creates collab-with-game requests (not repo contributions).
