Collaborate on Mini Cargo

Have an idea for the game? Want to contribute art, music, a level, or partner with us? Send a request and the team will take a look.

Submit a Collab Request

Your request is filed as a GitHub Issue in the Mini Cargo project board so nothing gets lost. You don’t need to share any code — just describe what you’d like to contribute to the game itself.

Other ways to reach us

Prefer chat? Join the #collab-requests channel on Discord. Existing requests (and the team’s replies) live on the public board at github.com/l-amb/mini-cargo-site/issues.
