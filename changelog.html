Changelog

What’s new on the Mini Cargo site.

Version 0.4 — 2026‑07‑27

  • Cargo-sorting mini-game on the homepage — click pairs of cargo by type to clear the dock against the clock.
  • Interactive roadmap with upvote buttons — players vote on what should ship next, persisted to localStorage.
  • Rotating notification toast system with gameplay tips and announcements.
  • Konami code easter egg (↑↑↓↓←→←→BA) triggers a cargo confetti animation.
  • Scroll progress bar at the top of the page.
  • Floating cargo emojis orbiting the hero game icon.
  • Stats demo mode: when live Roblox stats are unavailable (content-restricted), switch to demo simulated numbers. Chart.js updates dynamically.
  • Searchable FAQ — filter questions as you type.
  • Expanded FAQ: cargo physics, crossplay, and Discord invite questions added.
  • Feature cards now expand on click with detailed copy on Founder Pack, Daily Challenges, Leaderboards, and Cargo Physics.
  • Trailer section now offers a "Notify me when it's up" promise (saved to localStorage).
  • Game-style loading screen shown on the first visit — no flash of unstyled content.
  • Collaborate form reframed as game-collab requests (level designers, artists, musicians, testers, scripting) and adds a portfolio field; issue title/body clarified so GitHub Issues show what to collaborate on for the game, not the repo.
  • Updated trainer FAQ answers & less overlap across sections.

Version 0.3 — 2026‑07‑26

  • Real game icon in hero & nav (replaces the broken placeholder logo).
  • Live player count badge with one-click refresh from the Roblox API.
  • New Collaborate page — collab requests filed as real GitHub Issues for the game itself (not the repo).
  • FAQ accordion so newcomers can self-serve common questions.
  • Dark mode toggle, persisted between visits.
  • Mobile nav hamburger for small screens.
  • Working Chart.js graph (was missing, so the stats chart never rendered).
  • Removed broken Unsplash placeholders and the 404’ing Discord asset image.
  • Open Graph / social preview metadata so links look right when shared.

Version 0.2 — 2026‑07‑12

  • Added leaderboards and daily challenges (in-game).
  • Improved UI with light-blue theme and scroll animations.
  • Added a Collaborate section (placeholder Discord link).

Version 0.1 — 2026‑07‑20

  • Initial launch of the Mini Cargo site.
  • Basic stats and a Play button.
